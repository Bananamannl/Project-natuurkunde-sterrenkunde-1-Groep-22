# Analysing high frequencies in HoQI data 

The code in this repository is used for analysing data generated by HoQI's in the OmniSense sensor setup. It is specifically focused on the high frequency domains, where we try to find and eventually correct for higher order non-lineairities in the HoQI measurements to try and make them more accurate.

## Description

The files contained inside the folder Data_Analyse_Dataset_1 are the basic python code nessescary for extracting usefull data from the HoQI intensity measurements. The different parts of the program are broken up into several different files, with functions being used to keep the project tidy. Several important steps in here are: Extracting the measured voltage for all 6 HoQI's from the data file, turning these voltages into a Q1 and Q2 via the formulas given in Cooper, 2018, adjusting these Q1 and Q2 to remove noise and non-lineairity, using Q1 and Q2 to calculate the HoQI displacement, using the HoQI displacement and some geometry to calculate a cartesian movement and newtonian rotation in all three cardinal directions and analysing these with a spectral graph as well as a time series. We also make extensive use of the Numpy load and save functionality to quickly acces the large amounts of data that we need to analyse. The frequency, time series and Q1 and Q2 plots are contained in seperate folders as .png images. Data_analysis_Part_2 focuses instead on our processed data, and analysing the aforementioned high frequency distrubances and high order non-lineairities, with a focus on eventually eliminating them from the data to reduce noise. Lastly, there are the Animations and manimations folders, which will eventually contain the code for our Manim animation about a part of the project.

## Getting Started

You will definitly need to adjust a few things, mostly within the data extraction function to make it work with a different data file, but these should be minor adjustments. We think that the other functions will also work fine with other data as long as it is the relevant type for said function.

### Dependencies

* Confirmed to run on windows 10 and 11, Python 3.14
* User needs to have the following python libraries installed to run some of these files:
  * Manim Community (https://docs.manim.community/en/stable/installation.html)
  * GWpy (https://gwpy.readthedocs.io/en/stable/getting-started/)
  * PyVista (https://docs.pyvista.org/)

### Installing

You should be able to download or copy the repository and make a virtual enviroment, install the packages mentioned above, get a hold of a datafile full of HoQI data, adjust the data extraction function to fit the formatting of your data file and start analysing
