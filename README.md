# Analysing high frequency disturbances in HoQI data 

The code in this repository is used for analysing data generated by HoQI's in the OmniSense sensor setup. It is specifically focused on the high frequency domains, where we try to find and eventually correct for higher order non-lineairities in the HoQI measurements to try and make them more accurate.

## Description

The files contained inside the folder Data_Analysis_Part_1 are the basic Python code nessescary for extracting useful data from the HoQI intensity measurements. The different parts of the program are broken up into several different files, with functions being used to keep the project tidy. Several important steps in here are: extracting the measured voltage for all six HoQI's from the raw data file, turning these voltages into a Q1 and a Q2 via the formulas given in Cooper (2018), adjusting this Q1 and Q2 to remove noise and non-lineairity, using Q1 and Q2 to calculate the 'HoQI displacements', using these HoQI displacements and some geometry to calculate Cartesian movement and Newtonian rotation in all three cardinal directions, and analysing these movements with an ampltiude spectral density diagram as well as with a time series. We also make extensive use of the Numpy load and the Numpy save functionality to quickly get access to the large amounts of data that we need to analyse. The ASD's, time series and 'Q1 and Q2 plots' are contained in separate folders as .png images. The folder Data_Analysis_Part_2 focuses more on our already processed data. Important elements of this analysis are the aforementioned high frequency disturbances and high order non-lineairities, with a special focus on eventually eliminating these disturbances and non-linearities from the data to reduce noise. Lastly, there are both the Animations and manimations folders, which will eventually - at the end of the project - contain the code for our Manim animation.

## Getting started

You will definitly need to adjust a few things, mostly within the data extraction function, in order to make it work with a different data file. However, these should be minor adjustments. We believe that the other functions will work just as fine with other data, as long as the associated data is of the relevant type for the said function.

### Dependencies

* Confirmed to run on both Windows 10 and 11, with Python 3.14;
* User needs to have the following Python packages installed to run some of the included files:
  * Manim Community (https://docs.manim.community/en/stable/installation.html);
  * GWpy (https://gwpy.readthedocs.io/en/stable/getting-started/);
  * PyVista (https://docs.pyvista.org/).

### Installing

You should be able to download or copy the repository and to make a virtual enviroment, to install the packages mentioned above, to get a hold of at least one data file full of raw HoQI data, and to adjust the data extraction function to fit the format of your data file. After that, you should be able to start with the data analysis.
